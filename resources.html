Textbooks, Papers & Cheat Sheets

Accelerate your studies with essential textbooks, landmark papers that shaped computing, and printable engineering cheat sheets.

1. Seminal Computer Science Textbooks

Hand-picked, university-standard texts recommended for self-taught mastery:

Algorithms

Introduction to Algorithms (CLRS)

T. Cormen, C. Leiserson, R. Rivest, C. Stein

The definitive encyclopedic reference on sorting, graph algorithms, dynamic programming, and computational complexity.

Systems

Computer Systems: A Programmer's Perspective (CS:APP)

R. Bryant & D. O'Hallaron (Carnegie Mellon)

Bridge hardware and software: machine-level representations, processor architecture, cache hierarchies, and virtual memory.

Distributed Systems

Designing Data-Intensive Applications

Martin Kleppmann

The gold standard modern guide to storage engines, distributed consensus, stream processing, and data replication.

2. Seminal Research Papers That Built Computing

Year Paper Title Author(s) Significance
1936 On Computable Numbers, with an Application to the Entscheidungsproblem Alan Turing Introduced the concept of the Universal Turing Machine and formal computability.
1948 A Mathematical Theory of Communication Claude Shannon Founded Information Theory and defined the bit as the fundamental unit of data.
1978 Time, Clocks, and the Ordering of Events in a Distributed System Leslie Lamport Introduced logical clocks to reason about concurrent events across distributed nodes.
2017 Attention Is All You Need Vaswani et al. (Google Brain) Introduced the Transformer neural network architecture that powers modern generative AI.

3. Engineering Reference Cheat Sheets

Git Version Control Essentials

Terminal
# Stage and commit changes
git add -A && git commit -m "feat: optimize tree traversal"

# Interactive branch rebase against main
git fetch origin && git rebase origin/main

# Cleanly discard unstaged working directory edits
git restore .

# View compact commit graph
git log --oneline --graph --all

Linux Shell / Bash Power Commands

Bash Terminal
# Find files larger than 100MB
find / -type f -size +100M -exec ls -lh {} +

# Monitor listening network ports
ss -tulwn

# Inspect top CPU-consuming processes
top -o %CPU

# Stream logs with regex filter
journalctl -u nginx.service -f | grep -E "ERROR|404"
