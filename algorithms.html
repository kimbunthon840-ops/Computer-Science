2. Divide & Conquer: Quick Sort vs Merge Sort

Comparison-based sorting has a proven mathematical lower bound of Ω(n log n). The two industry standards divide inputs recursively:

Divide & Conquer

Merge Sort (Stable)

Splits array in halves until sub-arrays have 1 element, then merges sorted sub-arrays in O(n) linear time.

  • Time: Guaranteed O(n log n) in best, average, and worst cases.
  • Space: O(n) auxiliary memory needed for merging buffers.
  • Stability: Yes (preserves original order of equal keys).
In-Place Partitioning

Quick Sort (Cache-Optimized)

Picks a pivot, partitions array such that items smaller than pivot are left, larger are right, then recurses.

  • Time: Average O(n log n), worst-case O(n²) (mitigated by randomized pivot).
  • Space: O(log n) call stack space (in-place data swap).
  • Cache Friendliness: Extremely fast due to contiguous cache line sequential traversal.

3. Graph Traversal & Shortest Path

Graphs model networks, roads, dependencies, and web pages. Traversing vertices and relaxing edges is central to computer science:

Breadth-First Search (BFS)

Explores neighbors level-by-level using a Queue (FIFO). Finds the shortest path in unweighted graphs in O(V + E) time.

Depth-First Search (DFS)

Explores as deep as possible along each branch before backtracking using a Stack / Recursion. Used for cycle detection and topological sorting.

Dijkstra's Algorithm

Finds shortest paths from single source to all vertices on weighted graphs (with non-negative weights) using a Min-Priority Queue in O((V + E) log V).

dijkstra_shortest_path.py 
import heapq

def dijkstra(graph, start_node):
    distances = {node: float('inf') for node in graph}
    distances[start_node] = 0
    pq = [(0, start_node)]  # (distance, node)

    while pq:
        current_dist, current_node = heapq.heappop(pq)

        if current_dist > distances[current_node]:
            continue

        for neighbor, weight in graph[current_node].items():
            new_dist = current_dist + weight
            if new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                heapq.heappush(pq, (new_dist, neighbor))

    return distances

4. Dynamic Programming (Memoization vs Tabulation)

DP optimizes problems with overlapping subproblems and optimal substructure by caching computed results rather than recomputing exponentially:

Top-Down with Memoization

Keep recursive structure, but store returned values in a hash map or cache array. Only computes subproblems that are actually requested on the recursion path.

Bottom-Up with Tabulation

Iteratively fill a table from base cases up to target n. Eliminates call stack recursion overhead and often enables state-compression to O(1) space.
