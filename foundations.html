Foundations & Discrete Mathematics

Understand the mathematical bedrock of computing: number representation, bitwise operations, Boolean algebra, logic gates, and asymptotic Big-O runtime analysis.

1. Number Systems & Binary Representation

At physical silicon levels, digital computers process state through high and low voltage transitions representing binary digits (bits: 0 and 1). Numbers are expressed in base-2 (Binary), base-10 (Decimal), and base-16 (Hexadecimal).

Two's Complement (Signed Integers)

Standard method to represent negative numbers. To negate a number:
1. Invert all bits (One's complement: ~X)
2. Add 1 (~X + 1)

Two's Complement Example (-5)
+5  = 0000 0101
NOT = 1111 1010  (invert bits)
+1  = 1111 1011  (-5 in 8-bit)

Bitwise Operations in Systems

Direct silicon bit manipulation for low-level speed, network masking, and hardware register control:

  • AND (&): Masking bits (e.g. x & 1 checks parity)
  • OR (|): Setting specific bit flags
  • XOR (^): Toggling bits and fast in-place swaps
  • Shifts (<<, >>): Fast multiplication / division by powers of 2

2. Boolean Algebra & Logic Gates

Boolean algebra is the formal calculus of truth values (1 / TRUE and 0 / FALSE). In 1937, Claude Shannon proved in his master's thesis that electrical relay switches can compute any Boolean algebra equation.

Gate Symbol Truth Table Expression Behavior
AND A · B 1 AND 1 = 1, else 0 Outputs 1 only if BOTH inputs are high.
OR A + B 0 OR 0 = 0, else 1 Outputs 1 if AT LEAST ONE input is high.
NOT ¬A / A' NOT 0 = 1, NOT 1 = 0 Inverts the single input state.
XOR A ⊕ B 1 ⊕ 0 = 1, 1 ⊕ 1 = 0 Outputs 1 if inputs are DIFFERENT (odd parity).
NAND ¬(A · B) NOT (A AND B) Universal gate: can build ANY other logic gate!

De Morgan's Laws

Crucial for simplifying compiler boolean expressions and reducing hardware gate counts:

Law 1: ¬(A ∧ B) ≡ (¬A) ∨ (¬B)   |   "NOT (A AND B) is equal to (NOT A) OR (NOT B)"
Law 2: ¬(A ∨ B) ≡ (¬A) ∧ (¬B)   |   "NOT (A OR B) is equal to (NOT A) AND (NOT B)"

3. Asymptotic Notation (Big-O, Big-Ω, Big-Θ)

Asymptotic analysis evaluates how algorithm runtime and memory scale as input size n approaches infinity, independent of hardware clocks or compilers.

Upper Bound

Big-O (O)

Represents the absolute worst-case growth rate: f(n) ≤ c · g(n) for all n ≥ n₀.

Lower Bound

Big-Omega (Ω)

Represents the best-case floor: f(n) ≥ c · g(n). For comparison sorts, the lower bound is Ω(n log n).

Tight Bound

Big-Theta (Θ)

Binds both upper and lower limits asymptotically: c₁·g(n) ≤ f(n) ≤ c₂·g(n).

Notation Name n = 10 n = 1,000 Canonical Example
O(1) Constant Time 1 1 Hash table lookup, array index access
