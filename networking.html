Module 06 Distributed Network Stack Estimated 50 min

Computer Networking & Distributed Protocols

How billions of nodes communicate globally. Understand the 7-Layer OSI model, TCP reliable delivery vs UDP, DNS authoritative trees, HTTP/3 QUIC, and IPv4/IPv6 CIDR routing.

1. The 7-Layer OSI & TCP/IP Model

Network communication uses modular abstraction layers. As data descends the stack, each layer prepends a header containing metadata (encapsulation):

Layer 7: Application Layer (HTTP/3, DNS, SSH, SMTP) ▾

Interfaces directly with client applications. Generates raw payload data (e.g. JSON HTTP response, DNS query for domain IP).

Layer 4: Transport Layer (TCP vs UDP) ▾

Manages end-to-end communication and port multiplexing. TCP provides sequenced, guaranteed delivery with congestion control. UDP provides lightweight, connectionless datagram transmission for video streaming and gaming.

Layer 3: Network Layer (IPv4, IPv6, ICMP, Routers) ▾

Handles logical host addressing and routing across autonomous systems (AS) via protocols like BGP and OSPF. Routers make forwarding decisions based on destination IP.

Layer 2: Data Link Layer (Ethernet Frames, MAC, Switches) ▾

Transfers data frames between physically adjacent nodes on the same local subnet using 48-bit hardware MAC addresses. Bridges and switches operate here.

Layer 1: Physical Layer (Cables, Fiber Optics, Wi-Fi Radio) ▾

Transmits raw unstructured bits as light pulses down glass fiber or electromagnetic radio waves through air.

2. Evolution of Web Protocols (HTTP/1.1 ➔ HTTP/2 ➔ HTTP/3)

Legacy Standard

HTTP/1.1 (1997)

  • Plaintext ASCII protocol.
  • Suffers from Head-of-Line Blocking (only one request per TCP connection at a time).
  • Requires multiple parallel TCP sockets.
Multiplexing

HTTP/2 (2015)

  • Binary framing layer over single TCP stream.
  • Multiplexes dozens of concurrent requests.
  • HPACK header compression.
  • Still blocked if underlying TCP packet drops.
QUIC / UDP

HTTP/3 (Modern)

  • Runs on QUIC over UDP.
  • Zero head-of-line blocking across streams.
  • 0-RTT handshake reconnection.
  • Seamless connection migration between Wi-Fi and 5G.

3. IP Addressing & CIDR Subnetting Reference

Classless Inter-Domain Routing (CIDR) uses slash notation (/N) where N specifies the number of bits in the network prefix.

CIDR Prefix Subnet Mask Total Addresses ($2^{32-N}$) Usable Host IPs Common Use Case
/24 255.255.255.0 256 254 Standard home & office LANs
/28 255.255.255.240 16 14 Small cloud VPC database subnets
/30 255.255.255.252 4 2 Point-to-point router uplink links
/16 255.255.0.0 65,536 65,534 Large enterprise or university campuses
